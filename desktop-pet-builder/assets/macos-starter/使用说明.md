# 桌面宠物基础模板

编辑 config.json 中的应用名、称呼、角色、大小和提醒周期；把状态 PNG 放入 Resources，再运行 `python3 build.py`。需要 macOS 和 Apple Command Line Tools。构建结果在 dist。脚本不会覆盖已有 .app；更新时用 `--output dist/新版本.app`，验证后再替换。

不放图也能测试窗口，此时看到的是明确写着“素材占位”的原生图形，不是成品宠物。每个角色的 calm/happy/sleepy/concerned 图片须保持相同画布、比例和落脚点；缺少状态图回退到 calm。

单击回应，双击一起玩，拖动移动。菜单栏“伙伴”或右键可调大小、隐藏、找回、退出。重新打开正在运行的应用会显示伙伴。提醒可关闭或延后十分钟，隐藏后仍按开关设置提醒。

`--self-test` 检查模型；`--smoke-test` 用隔离设置域检查原生行为并自动退出；追加 `--qa-dir <目录>` 导出实际窗口画面。`--launch-check` 走正常启动和保存路径，一秒后退出，用于唯一测试项目的最终验证。

模板提供基础点击、双宠位移、心情、提醒和保存。精细转身、多帧表情、完整双宠剧情、五阶段使用时长需要依据 skill 继续实现。完成应用可以不联网运行。当前架构由构建机器决定，构建的 ad-hoc 签名不等于可跨电脑信任的发行签名。
