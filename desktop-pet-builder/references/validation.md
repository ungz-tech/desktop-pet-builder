# 验证与交付

## 按变更选择检查

| 变更 | 有价值的验证 |
| --- | --- |
| 提醒/状态模型 | 到期前后边界、同刻不重复、稍后、关闭/恢复、真实与测试提醒、睡眠间隙 |
| 点击/拖动 | 一次输入对应一次动作，移动中的身体命中，透明空白穿透，拖动不会算作点击 |
| 图集/动画 | 正反朝向、开始/结束/中断、比例与锚点、尾巴/剑/托盘完整，小尺寸可辨 |
| 多组合/保存 | 正常启动路径、设置域隔离、只显示本组、迁移不覆盖、用户记录保留 |
| 使用时长 | 空闲/隐藏暂停、真实恢复只欢迎一次、预览不改计时、提醒优先 |

模板命令为 python3 build.py；二进制支持 --self-test、--smoke-test 和 --smoke-test --qa-dir <目录>。smoke test 自动结束，不影响真实记录。测试覆盖模板的基础能力；扩展新动作后补上针对新增行为的检查。

用模型时间快速过边界，同时运行真实 NSApplication/NSView。仅编译或只测模型不能证明正常启动成功。图像命中和窗口裁切应从实际渲染检查，不用“文件存在”代替画面验证。

## 分享前

保留源码、配置 schema/说明、素材与原始提示词、构建命令。不要打包编译缓存、日志、绝对个人路径、昵称与亲近度记录。模板 ZIP 只带开发用内容，不带原用户角色素材或已有 .app。

原生应用实际验证后的 GIF/检查图可以用于展示。清楚标注“已运行检查”“模拟时间验证”“平台未验证”；不要把每个阶段模拟通过表述成已经实等两小时。

## 给使用者的交付

简短说明应用入口、点击/双击/右键、隐藏后找回、大小、提醒、退出，以及目标系统。用户要求分享 skill 时，打包完整 skill 文件夹并附独立安装说明；只准备文件，不擅自发布到账号或给别人发消息。
